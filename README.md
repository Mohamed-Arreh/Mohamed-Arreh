- **[auto-shop-reactivation-saas](https://github.com/Mohamed-Arreh/auto-shop-reactivation-saas)** : a multi-tenant SaaS that helps auto repair shops recover declined work through AI-personalized SMS outreach. Next.js, Supabase (multi-tenant with RLS), Twilio, Claude.

Based in Ottawa. Open to remote and hybrid roles.
